# Amadeus 3.52

Amadeus 是模块化科研候选筛选、证据整合与配方研发平台，当前主要用于颅骨透明化候选筛选和配方探索。软件是研究原型；数值试算和证据提示不证明实验效果、安全性或临床适用性。

## 当前主要能力

- 导入 CSV/XLSX 用户候选，明确字段映射，运行配置化规则、身份/结构与 RDKit 描述符、Hansen 距离筛选，按 run_id 隔离结果并导出报告；保留 SeeThrough 参考筛选。
- 管理候选工作草稿与确认批次，记录用途实验终点，形成当前颅骨透明化用途摘要、约束和特征状态。
- 独立公开证据入口支持 PubChem、CompTox、NIST、ThermoML：统一 Provider 注册、Repository 存储、Resolver 条件采用、单位/身份处理、冲突保留与原始响应缓存。CompTox 无密钥时明确未配置；ThermoML 需要明确的官方文档及物质身份。
- 组装带明确投料单位的完整配方，按指标选择 RI、黏度、自由扩散、渗透压和水活度模型；包括仅适用于甘油–水的 Cheng_2008 黏度模型。有效实测优先，缺失保留状态和原因。
- 以独立候选库进行有限预算粗搜、配方约束与 Pareto 排序；已知体系用于验证及搜索完成后的对照，不作为发现种子或排名标签。
- Target Profile 1.0 支持 JSON 规格驱动发现模式的硬约束、目标和报告，搜索前明确预检；目标沿用现有 Pareto 排序，缺失不填数值。支持五类现有配方物性、成本及分子量硬约束/报告。

## 模块化特征

公共证据契约与具体数据库 Provider 分开，Provider 相互独立；证据存储支持 DuckDB、SQLite、Parquet，并可注入 Repository。物性模型各负责独立指标，经注册表和 `预测(配方, 上游)` 契约选择，声明上游依赖。多个功能插件由核心流程编排。

内部架构、接口、路线图与当前任务集中在 [项目说明_1.0](./项目说明_1.0/00_项目定位与边界.md)，README 不提供新的功能需求。

## 安装与运行

使用与现有依赖相容的 Python 环境；当前本地验证环境使用 Python 3.12.3。安装依赖时以项目 requirements 为准。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install -r requirements-public-data.txt
streamlit run 启动程序.py
```

在“配方发现与验证”中选择验证或发现模式。发现候选池默认为空，须导入独立库或明确载入程序试跑演示库。命令入口示例：

```powershell
python 运行配方研发.py 验证
python 运行配方研发.py 发现 --候选库 用户明确提供的候选库.json
python 运行配方研发.py 发现 --候选库 用户明确提供的候选库.json --target-profile 用户目标规格.json
```

命令报告写入自动创建的根 `运行记录/`；用户导入流程产物保存在 `数据/运行记录/<run_id>/`。本地筛选与试算不需要在线来源密钥；可选 CompTox 查询使用本机环境变量 `COMPTOX_API_KEY`，不在文件中保存凭据。

## 当前限制

- 新公开物性当前独立查询、存储和解析，未接旧 descriptor 宽表或配方计算。旧毒理页面公开通道仍仅使用 PubChem GHS；GHS 是危险提示，不参与 A/B/C/D 实验条件匹配。
- 配方局部细化已从规范化质量分数生成邻域并重新评价；有限预算局部搜索不保证全局最优。
- Target Profile 尚未接 UI 或全面公开证据层。未绑定指标、delivery/experiment、分子 objective、单位不兼容及无法满足的证据要求会预检失败；发现入口没有配方实测输入，不能运行 measured_only 物性要求。GP 与 BoTorch 未启用，无真实训练模型；当前没有 Agent。
- 物性公式为适用条件内的初筛近似；自由扩散对应指定探针，不是组织递送。未知毒理、混溶性、滞留和未量化不确定度不当低风险。
- 在线来源实现与离线/模拟测试不等于所有实时接口或远程认证已验收。

## 数据来源与许可

SeeThrough 补充表、结构映射和参考标签仅用于对应演示及对照，程序不覆盖论文原始表；来源、署名与第三方许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。公开证据保留各来源、文献、条件、形式及原始响应关系，不覆盖或静默平均冲突。
