## 已解决

### TD-01 比例细化混用绝对用量和分数（已修复）

根因是细化读取已经换成绝对用量的返回定义。现在只读取组装校验后的 `成分[*].质量分数`，经原 `组装定义` 生成标准质量分数邻域，与粗搜规范化定义签名比较；组装插件的 g/mL/mol 行为未改。回归验证 20%/80% → 15%/85%、25%/75%，和为 1、各项正、可以重新组装。默认内存演示粗搜 52、累计定义/排序 65、失败 0，旧测试不再接受已知失败。

## 当前真实技术债

### Target Profile v1 执行边界

已接发现与 CLI、现有约束/Pareto，未接 UI 或全面公开证据层。仅五类 formulation 物性/成本和 molecule 分子量硬约束/报告可执行；其余指标/作用域、分子目标聚合、布尔 equals 与可靠单位换算尚未支持。发现无配方实测输入；成本 derived、分子量来源类型未细分，不能满足 measured/predicted 门槛，预检明确失败。不得新增空框架或伪造证据。

### TD-02 功能插件私有调用和内部函数依赖

确认批次描述符插件实例化 RDKit普通描述符插件，调用 `_描述符值/_Fig1c标签`；比例优化导入自动组合的 `组装定义`，发现约束导入比例优化的 `组成签名`。这些依赖妨碍替换，尤其私有调用违反稳定契约原则。共享公开纯算法契约和业务插件互调需区分，当前不扩大耦合。

### TD-03 界面越界与用途绑定

配方构建页面导入核心私有 `_配置对象`，身份审核页面直接调用人工确认功能插件。确认草稿与用途评估明确限制当前颅骨用途，用户 HSP 前置计算仍绑定 SeeThrough 参照。公共平台定位不等于这些代码已通用化；当前不改 UI 或业务流程。

### TD-04 接口完整性和替换注入不足

功能插件上下文/返回 Any，注册表不验证且同标识覆盖；数据管理抽象接口未声明下游需要的软件数据库写入等方法。研发生成/约束/排序直接实例化，只有物性等能注入。公开聚合允许 ProviderRegistry、Repository、raw cache 注入，但直接构造 EvidenceResolver，尚无 Resolver 注入点。不得描述为全平台所有实现均可无改动替换。

### TD-05 数据与标识边界

旧文件数据管理只保护论文原始目录，其他表格/导出标识未全面限制在目标目录；运行管理对上传/导出/运行路径增强检查，但继承表格拼接仍有缺口。公开身份接受本地候选编号回退为全局 compound_id，共享证据库存在跨运行碰撞风险；已有 observed structure 隔离不能涵盖空结构场景。

### TD-06 近似与缺失覆盖不足

用途描述符聚合根据单位包含 `%`/“百分”判定可加权，并对有值成分重新归一化；可能混基准、在部分缺失时仍输出近似值。虽然已标记筛选近似，不能当完整真实混合物物性。直接物性入口部分温度/波长一致性依赖来源，校验弱于完整组装；公式区间与误差大多未量化。

### TD-07 多种存储路径与旧报告契约

用户 run_id 目录、旧固定结果目录、全局确认/用途 CSV 与 CLI 根报告目录并存；用途同批次覆盖而非不可变历史。人体/动物模式与模型结果标识不一致已在专项表说明。删除历史根运行输出不改变这些代码约定；`数据/` 内当前所需数据不清理。

### TD-08 兼容层与静态未使用线索

工厂旧别名、PubChem 旧类/插件标识、CompTox 旧类名、用途运行器反向转发和最终结果回退仍存在，兼容意义明确，不能机械删除。静态看到数据管理的 Any、毒理分析的 field、PubChem parser 的 replace 导入未被本文件使用；这只是未使用导入线索，不足以宣称整块逻辑是死代码。异常类空 body、SQLite 自动事务钩子和 Parquet close 的 pass 都有当前实现理由，不视为未实现功能。

### TD-09 部分测试写真实项目数据

部分论文端到端/插件单测/图表测试以真实根目录执行并覆盖结果，本轮不运行这些测试。后续回归需临时数据根或用户明确产物范围。冻结 benchmark 与创建发布请求的辅助脚本是本地测试材料，保留但不自动执行。
