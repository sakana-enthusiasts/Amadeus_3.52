# 项目定位与边界

当前版本：3.52。核对日期：2026-09-18。本目录是当前项目架构、接口、路线图与任务范围的唯一内部权威说明。开始任务先读 `00`–`07` 和相关模块文档，再核对真实代码；说明与实现冲突时重新检查并纠正说明，不按旧描述猜测功能。

## Amadeus 是什么

Amadeus 的长期定位是“模块化、可扩展、可替换的科研候选筛选、证据整合、配方研发和后续实验闭环平台”。当前以颅骨透明化候选筛选和配方研发作为主要实际应用场景，保留 SeeThrough 参考流程，但底层架构不能被设计成只服务一个固定研究计划。

当前平台已有用户候选导入、配置化筛选、身份与结构处理、证据整合、配方组装和物性计算等能力。后续实验闭环是定位中的方向，不表示已有已训练预测模型或可运行的闭环优化。

## 公共能力与用途能力

- 公共能力：功能插件契约与注册、数据管理、属性/规则契约、公开证据身份/条件/单位/冲突及 Repository/Resolver、Target Profile 数据契约、独立指标物性模型及注册表。
- 用途能力：当前颅骨透明化配置、目标、成分/配方/终点/约束评价，以及 SeeThrough 参考规则、结构映射和标签对照。

当前用途插件可依赖公共结果；用途不得成为底层公共模块的硬编码架构假设。现有确认草稿等仍有场景绑定，作为当前实现限制记录，不把它上升为长期设计要求。

## 版本目录与说明边界

用户通过整体复制版本目录工作，例如 `3.5 → 整体复制 → 3.51 → 整体复制 → 3.52`。当前根目录已经是完整版本，不创建 `versions/`、`src/`、`app/` 或新项目外壳，不改变现有代码目录。

README 只介绍当前软件，模块详细说明位于 `模块/`。许可声明、运行结果、研究计划、PPT、论文、实验方案、历史检查与冻结的外部评估材料不得自动转成软件需求。出现某个概念、字段或“未来/预留”字样不授权增加对应功能。

## 上层自动化与当前边界

未来 Agent 或其他自动调度系统只能作为现有稳定接口和流程的上层调用者。底层不得依赖 Agent；当前不实现 Agent、不创建空 Agent 框架、不为它改写业务代码。

当前阶段是 TD-01 修复与 Target Profile Execution v1：沿用现有发现、约束和 Pareto 路径，新增中性指标绑定与执行计划，不改 UI、不扩展其他模型或公开证据层、不处理其他技术债。具体范围见 [06_当前版本任务](06_当前版本任务.md)。未经用户明确要求，不 commit、push、创建 PR 或发布。
